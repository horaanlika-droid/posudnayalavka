# Посудная лавка · Telegram Mini App + бот

Магазин барного стекла: витрина в стиле официального iOS-клиента Telegram, корзина,
оплата картой через ЮKassa, счёт для юрлиц, чат поддержки и админ-панель внутри бота.

Каталог (75 позиций, цены и фото) собран автоматически из прайса `PL_avgust_2026.pdf`.

---

## Что внутри

| Часть | Путь | Описание |
|---|---|---|
| Mini App | `webapp/` | Витрина без сборки: чистый ES-модульный JS, iOS-навигация, тёмная тема бренда |
| API | `src/server.js` | Каталог, корзина, заказы, оплата, поддержка, печатная форма счёта |
| Бот | `src/bot/` | Клиентские команды + админ-панель (заказы, поддержка, каталог, статистика, рассылка) |
| Данные | `data/catalog.json` | Товары из PDF; правки админа хранятся отдельно в `data/db.json` |
| Генератор каталога | `scripts/build_catalog.py` | Пересобирает каталог и фото из нового прайса |

Всё работает в **одном процессе** (`npm start`) — так проще всего для BotHost.
При желании части разносятся: `MODE=web` (только сайт) и `MODE=bot` (только бот).

---

## Быстрый старт

```bash
npm install
cp .env.example .env      # заполнить BOT_TOKEN, ADMIN_IDS, PUBLIC_URL и ключи
npm start
```

Открыть `http://localhost:3000`. Без `BOT_TOKEN` приложение поднимается в режиме
предпросмотра (вход без Telegram), бот при этом не запускается.

---

## Деплой на BotHost

1. Загрузить репозиторий (Git или архивом).
2. Node.js **20+**, команда запуска — `npm start` (устанавливается автоматически из `package.json`).
3. В разделе с переменными окружения задать значения из таблицы ниже.
   **Никаких токенов и ключей в коде нет — только переменные окружения.**
4. `PUBLIC_URL` — публичный HTTPS-адрес приложения, который выдаёт хостинг.
   Он нужен для кнопки Mini App, ссылок на счета и вебхука ЮKassa.
5. После первого запуска в @BotFather у бота уже будет кнопка меню «Магазин»
   (ставится автоматически, если `PUBLIC_URL` начинается с `https://`).

### Переменные окружения

| Переменная | Обязательно | Назначение |
|---|---|---|
| `BOT_TOKEN` | да | Токен бота от @BotFather |
| `ADMIN_IDS` | да | ID администраторов через запятую (узнать: @userinfobot) |
| `PUBLIC_URL` | да | `https://ваш-домен` без слэша на конце |
| `BOT_USERNAME` | желательно | Имя бота без `@` — для ссылок возврата после оплаты |
| `PORT` / `HOST` | нет | По умолчанию `3000` / `0.0.0.0` |
| `MODE` | нет | `all` (по умолчанию), `web`, `bot` |
| `ALLOW_DEV_AUTH` | нет | `1` — разрешить вход без Telegram (только для отладки) |
| `YOOKASSA_SHOP_ID` | для оплаты картой | shopId из личного кабинета ЮKassa |
| `YOOKASSA_SECRET_KEY` | для оплаты картой | Секретный ключ ЮKassa |
| `YOOKASSA_VAT_CODE` | нет | Ставка НДС для чека: 1 — без НДС, 2 — 0%, 3 — 10%, 4 — 20% |
| `YOOKASSA_RECEIPT` | нет | `1` — отправлять чек 54-ФЗ (нужен e-mail или телефон покупателя) |
| `SELLER_*` | для счетов | Реквизиты продавца (см. `.env.example`) |
| `INVOICE_PREFIX`, `INVOICE_VAT` | нет | Префикс номера счёта и НДС в счёте (`none`/`20`/`10`) |
| `FREE_SHIPPING_FROM` | нет | Порог бесплатной доставки по России, ₽ (по умолчанию 30000) |
| `SHIPPING_COST` | нет | Стоимость доставки, если сумма меньше порога (по умолчанию 790) |
| `MIN_ORDER_TOTAL` | нет | Минимальная сумма заказа |

### Вебхук ЮKassa

В личном кабинете ЮKassa указать URL уведомлений:

```
https://ваш-домен/webhook/yookassa
```

События: `payment.succeeded`, `payment.canceled`. Даже без вебхука оплата
подтвердится — витрина сама опрашивает статус платежа после возврата пользователя.

## Функции магазина (для клиента)

- **Главная** — слайдер бренда, категории, «Популярное», «Новинки», информация о доставке.
- **Каталог** — 7 категорий, поиск, сортировка (цена, объём, название), фильтры «только новинки»,
  «только в наличии», ограничение цены.
- **Карточка товара** — фото на чёрном фоне, артикул, объём, характеристики, похожие позиции,
  добавление в корзину через нативную кнопку Telegram.
- **Корзина** — количество, прогресс до бесплатной доставки, пересчёт итогов.
- **Оформление** — контакты, способ доставки (курьер Москва / СПб, СДЭК-ПЭК, самовывоз),
  адрес, комментарий и выбор оплаты:
  - **картой онлайн** — ЮKassa (карты, СБП), чек 54-ФЗ, автоподтверждение платежа;
  - **счёт для юрлица** — поля компании (название, ИНН, КПП, адрес, e-mail), счёт
    формируется сразу и открывается печатной формой A4 (`/invoice/:id`), сумма прописью.
- **Заказы** — статусы (Новый → Оплачен → Собирается → Отправлен → Доставлен), состав,
  реквизиты, кнопки «Проверить оплату», «Открыть счёт», «Отменить».
- **Избранное** и **Кабинет** — статистика покупок, доставка и оплата, о бренде, контакты менеджеров.
- **Чат поддержки** — сообщения уходят администраторам в бот, ответы приходят в чат
  внутри приложения и в личку бота.
- **Каталог в боте** — команда `/catalog` и кнопка в сообщении бота позволяют листать
  категории и товары прямо в Telegram, даже если Mini App ещё не открывали.

## Админ-панель (в боте)

Команда `/admin` доступна только ID из `ADMIN_IDS`.

- 📦 **Заказы** — списки (все / активные / оплаченные / по счёту), поиск по номеру,
  карточка заказа с составом и контактами, смена статуса в одно нажатие,
  уведомление клиента при каждой смене, ссылка на счёт.
- 💬 **Поддержка** — список диалогов с непрочитанными, история переписки,
  ответ кнопкой «Ответить» **или** обычным reply на пересланное сообщение.
- 🍸 **Каталог** — поиск товара по названию/артикулу, изменение цены, возврат цены из прайса,
  «нет в наличии», скрытие из витрины. Правки применяются мгновенно и переживают перезапуск.
- 📊 **Статистика** — заказы за сутки/неделю, выручка, средний чек, топ товаров, пользователи.
- 📣 **Рассылка** — предпросмотр и отправка всем пользователям с ограничением скорости.
- ⚙️ **Настройки** — какие интеграции подключены (проверка переменных окружения).

Уведомления администраторам приходят автоматически: новый заказ, оплата, обращение в поддержку.

## Обновление каталога

При новом прайсе положить PDF в корень и выполнить:

```bash
pip install pymupdf pillow numpy
python3 scripts/build_catalog.py PL_novyy_prays.pdf
```

Скрипт заново соберёт `data/catalog.json` и вырежет фото товаров в
`webapp/assets/products/` (артикул = имя файла). Ручные правки цен из бота
сохраняются отдельно и не затираются.

## Технические детали

- Зависимости только две: `express` и `grammy` — нет сборки, нет нативных модулей.
- Хранилище — JSON-файл `data/db.json` с атомарной записью (заказы, диалоги, правки каталога,
  избранное, корзины). Файл не коммитится.
- Авторизация — проверка подписи `initData` Telegram WebApp (HMAC-SHA256) на каждом запросе.
- Бот работает на long polling — вебхук и белые списки IP не нужны.
- Витрина адаптирована под iPhone: safe-area, нативные кнопки Telegram (MainButton, BackButton),
  тактильная отдача, iOS-переходы между экранами, blur-навбар и таб-бар.
